# Thala — ফ্যামিলি মিল প্ল্যানার

বাংলাদেশি পরিবারের জন্য মাসিক বাজেট আর প্রত্যেক সদস্যের ক্যালোরি মিলিয়ে ৭ দিনের মিল প্ল্যান, গ্রোসারি লিস্ট ও রেসিপি।
*A Bengali-first meal planner: monthly budget + per-member calories → weekly plan, grocery list, recipes.*

## পেজগুলো
| URL | ফাইল | কী আছে |
|---|---|---|
| `/?page=Landing` | `Landing.dc.html` | ল্যান্ডিং পেজ |
| `/?page=App` | `App.dc.html` | মোবাইল অ্যাপ: ফ্যামিলি · বাজেট · লিস্ট · রেসিপি · প্ল্যান |
| `/?page=Main` | `Main.dc.html` | ফ্যামিলি ক্যালোরি ক্যালকুলেটর |

## চালানোর নিয়ম
`file://` দিয়ে খুললে চলবে না, একটি সার্ভার লাগবে:

```bash
python3 -m http.server 8080      # অথবা: npm start
# খুলুন http://localhost:8080
```

`App.dc.html` ইত্যাদি সরাসরি খুললেও (যেমন Netlify-তে `/app.dc`) পেজ নিজে `index.html?page=App`-এ চলে যায়, তাই লিংক ভাঙে না।

## GitHub Pages / Netlify
1. নতুন repository বানিয়ে এই ফোল্ডারের সব ফাইল (কোনো সাব-ফোল্ডার নেই, সব একই লেভেলে) আপলোড করুন।
2. Settings → Pages → Branch: `main` / root।
3. `https://<user>.github.io/<repo>/` এ সাইট চালু হবে।

## কীভাবে কাজ করে
`Landing.dc.html`, `App.dc.html`, `Main.dc.html` ফাইলগুলো Claude Design ক্যানভাসের Design Component ফরম্যাটে লেখা।
`dc-lite.js` একটি ছোট runtime (কোনো dependency নেই) যা একই ফাইল সাধারণ ব্রাউজারে চালায়,
তাই ক্যানভাস আর GitHub সাইট একই সোর্স ব্যবহার করে।

## ফিচার
- ফ্যামিলি: সদস্যের ছবি (ক্যামেরা/গ্যালারি), ছবিতে ট্যাপ করলে নাম-বয়স-ওজন-ক্যালোরি সহ পপ-আপ
- বাজেট: মাসিক বাজেট (৳২,০০০ থেকে), দোকানভেদে তুলনা, সবজি-মাছ-মাংসের দাম এডিট
- লিস্ট: নিজের আইটেম; স্ক্রল করলেও হেডারে কেনা/বাকি/মাসিক হিসাব; তারিখ ধরে সপ্তাহভিত্তিক মাসের সেভ-বক্স (সেভ করা তালিকা আবার খোলা ও আপডেট করা যায়)
- রেসিপি: নিজের রেসিপি তৈরি/এডিট
- প্ল্যান: ক্যালেন্ডার (তারিখ ও বার), সাপ্তাহিক চার্ট → দিন → তিন বেলা → ডিশের প্লেট পপ-আপ ও নিজের তোলা ছবি
- আজকের রিমাইন্ডার: অ্যাপ খুললেই পপ-আপে আজকের নাস্তা/দুপুর/রাতের ডিশ ও কোন জিনিস কতটুকু লাগবে (এটি অ্যাপের ভেতরের নোটিফিকেশন; ফোনের লক-স্ক্রিন পুশ নয়)
- বাজেট: মাসে কোন ক্যাটাগরিতে কত টাকায় কী কী কিনতে হবে
- রেসিপি তালিকায় যেকোনো রেসিপিতে ট্যাপ করলে প্লেটের পপ-আপ আসে; সেখান থেকে বেলা ও দিন বেছে "সেভ করে প্ল্যানে যোগ করুন"
- নিজের তোলা ডিশের ছবি প্লেটের ভেতরে গোল হয়ে বসে
- অটো-সেভ: ফ্যামিলি, ছবি, প্ল্যান, দাম, বাজার ও মাসের হিসাব এই ডিভাইসের ব্রাউজারে (localStorage) সেভ হয়; রিফ্রেশ করলে বা পরে আবার খুললে থাকে
- ঐচ্ছিক Google লগইন + ক্লাউড সেভ (নিচে দেখুন), যাতে অন্য ফোনেও একই ফ্যামিলি ও ছবি পাওয়া যায়

## Google লগইন ও ক্লাউড সেভ চালু করা (ঐচ্ছিক, প্রায় ১০ মিনিট)
ডিফল্টে বন্ধ থাকে; তখনও অটো-সেভ কাজ করে। চালু করতে (Firebase Spark প্ল্যানে বিনা খরচে, কার্ড লাগে না):
1. https://console.firebase.google.com এ নতুন প্রজেক্ট বানান।
2. Project settings → Your apps → Web (`</>`) অ্যাপ যোগ করে config কপি করুন।
3. `firebase-config.js` ফাইলে `window.THALA_FIREBASE = { ... }` বসান।
4. Authentication → Sign-in method → **Google** চালু করুন। Settings → Authorized domains এ আপনার সাইটের ডোমেইন (যেমন `xxx.netlify.app` বা `user.github.io`) যোগ করুন।
5. Firestore Database বানান, তারপর Rules এ এটি দিন:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```
ছবিগুলো ছোট করে Firestore-এ রাখা হয়, তাই Cloud Storage বা বিলিং লাগে না। Firestore-এর বিনা খরচের সীমা প্রতিদিন ২০,০০০ লেখা ও ৫০,০০০ পড়া (Firebase pricing plans ডকুমেন্ট অনুযায়ী)।
লগইনের পর ফ্যামিলি ট্যাবে "Google দিয়ে লগইন করুন" বাটন আসে। নতুন ডিভাইসে লগইন করলে সবচেয়ে নতুন সেভটি নেওয়া হয়।
এই ক্লাউড অংশ আসল Firebase প্রজেক্টে আমি চালিয়ে দেখিনি; নকল ব্যাকএন্ড দিয়ে অ্যাপের দিকটা টেস্ট হয়েছে।

## খাবারের ছবি (dish-01.jpg … dish-57.jpg)

- ৫৭টি খাবারের ছবি গোল করে ক্রপ ও জুম করা (৫২০×৫২০ JPEG)। ছবি `App.dc.html`-এর `DISH_IMG` ম্যাপে রেসিপি আইডি (`x01…x57`) অনুযায়ী বসানো।
- প্লেট পপ-আপে ছবি গোল হয়ে প্লেটের ভেতরে বসে, সাথে ঢোকার মোশন, ধীর জুম ও ধোঁয়া। `prefers-reduced-motion` চালু থাকলে মোশন বন্ধ থাকে।
- ছবিগুলো অ্যাপের মতো একই ফোল্ডারে (ফ্ল্যাট) রাখতে হবে।
- নিজের তোলা ছবি আপলোড করলে সেটা এই ছবির জায়গায় বসবে। ছবি সরালে এই ছবি ফিরে আসবে।

## প্রজেক্ট হাব (Landing ও অ্যাপের ফ্যামিলি ট্যাব)

- উপরে সার্চ বার, তারপর এডিট বাটন, তারপর ড্রপডাউন তীর। তীরে চাপলে কার্ডগুলো গুটানো বা খোলা যায়। পেজ খুললে সব কার্ড খোলা থাকে।
- সাইটের তালিকা `App.dc.html` ও `Landing.dc.html`-এর `HUB_SITES` অংশে আছে। কার্ডের ছবি `hub-*.jpg` (এই ফোল্ডারেই রাখতে হবে)।
- এডিট বাটনে নির্বাচিত কার্ডের নাম ও লিংক বদলানো, মোছা বা নতুন কার্ড যোগ করা যায়। পরিবর্তন ব্রাউজারে সেভ থাকে।
